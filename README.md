# ✈️ Flight Delay & Performance Analysis Using Tableau

## 📌 Project Overview

This project analyses flight data to understand flight delays, cancellations, and on-time performance. An interactive Tableau dashboard was developed to explore flight performance and identify patterns in delays.

## 🎯 Project Objectives

- Analyse on-time and delayed flights.
- Understand flight cancellation patterns.
- Identify common reasons for flight delays.
- Explore changes in flight delays over time.
- Compare flight performance across airlines and airports.

## 🛠️ Tools & Technologies

- Tableau
- Microsoft Excel
- Power BI (Data Preparation)
- Data Cleaning
- Data Visualisation

## 📊 Key Performance Indicators (KPIs)

- Total Flights
- Delayed Flights
- Average Delay (Minutes)
- Cancellation Rate
- On-Time Performance

## 📈 Dashboard Features

- On-Time vs Delayed Flights
- Cancellation vs Non-Cancellation Analysis
- Monthly Delay Trends
- Flight Delay Reasons
- Airline Performance Comparison
- Airport Delay Analysis

## 🔍 Key Analysis

- Compared on-time flights with delayed flights.
- Examined flight cancellations and non-cancellations.
- Explored delay patterns using available flight date and time fields.
- Analysed possible differences in performance across airlines and airports.

## 💡 Business Value

This analysis helps users understand flight performance, identify delay patterns, and explore factors that may contribute to operational inefficiencies. The findings can support further investigation and data-driven decision-making.
